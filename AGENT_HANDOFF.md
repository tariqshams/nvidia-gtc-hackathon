# Esports Hype Caster - Agent Handoff Document

## Project Overview
This project is an AI-powered Esports Hype Caster built with **Next.js 16.2.0 (App Router)** and **Tailwind CSS**. It takes a user-uploaded gameplay video and a target "excitement level", analyzes the video natively using an NVIDIA Vision Language Model (VLM), generates a hype narration script using a second advanced Language Model, and plays the narration back synchronously over the video using the browser's native `SpeechSynthesis` API.

## Core Technologies
- **Framework:** Next.js (TypeScript, Turbopack Server)
- **Styling:** Tailwind CSS (v4) with Lucide React icons
- **AI Models (via NVIDIA NIM):**
  - **Vision:** `nvidia/nemotron-nano-12b-v2-vl` (handles direct base64 video payloads)
  - **Text Generation:** `nvidia/nemotron-3-super-120b-a12b` (hype script writing)
- **Audio:** Web Speech API (`SpeechSynthesisUtterance`)

## Architecture & Data Flow

### 1. Frontend (`app/page.tsx`)
The UI is split into two distinct visual columns:
- **Left Panel (Setup):** Contains the file uploader and an excitement slider (1-10). Displays an interactive input preview player of the raw footage.
- **Right Panel (Output/Agent Trace):**
  - **Execution Log:** Streams real-time progress events from the backend API using Server-Sent Events (SSE).
  - **Final Output:** Only appears when processing finishes. Contains the locked video player, a custom "Play Hype Cast" button, and the generated script box.

**Critical Frontend Features to Note:**
- **Synchronized Audio Ducking:** Clicking "Play Hype Cast" reduces the native video volume to `15%`, allowing the TTS caster to be heard clearly over gameplay.
- **Chrome Garbage Collection Patch:** The `SpeechSynthesisUtterance` instance is explicitly anchored to `window._hackathonUtterance` to prevent V8 from prematurely garbage collecting the ongoing speech (a notorious Chrome bug).
- **Synchronous WebSpeech API:** The `window.speechSynthesis.speak()` call executes synchronously on the user's click stack without timeouts to strictly satisfy browser gesture policies.

### 2. Backend API (`app/api/process/route.ts`)
The orchestrator is a completely serverless Next.js API route that handles the AI pipeline and streams status back to the client (`text/event-stream`).

**Pipeline Steps:**
1. **Video Ingestion:** Accepts the `FormData` multipart video upload and converts it to a Node `Buffer`.
2. **Direct VLM Parsing:** Encodes the raw buffer to `base64` and embeds it directly into an OpenAI-compatible payload format using the `video_url` standard.
   - *Note:* We use the `/no_think` system prompt because NVIDIA's VLM endpoint limits video modalities to direct answers.
3. **Script Generation:** The description generated by the nano vision model is passed as context to `nemotron-3-super-120b-a12b`, alongside the excitement level param, to write the 2-3 sentence hype script.
4. **SSE Dispatch:** Sends `|TTS_READY|{Script Content}` string so the React frontend knows to decouple the output and render the custom player.

## Missing or Future Features
- The pipeline previously relied on `ffmpeg` to extract static frames; this was completely stripped out in favor of native video passing. Do not accidentally reintroduce `ffmpeg-static` or `ffprobe-static` as they are now dead dependencies.
- The TTS engine is currently reliant on the OS-level voices (`window.speechSynthesis`). Next iterations could integrate a dedicated NVIDIA Audio2Face or an external TTS API for far higher quality synthetic voice acting.

## Environment Variables Required
`NVIDIA_VILA_API_KEY` (Used for the Nemotron Nano VLM endpoint)
`NVIDIA_VILA_MODEL_ID` (Should be `nvidia/nemotron-nano-12b-v2-vl`)
`NVIDIA_NEMOTRON_API_KEY` (Used for the Script Generation endpoint)
`NVIDIA_NEMOTRON_MODEL_ID` (Should be `nvidia/nemotron-3-super-120b-a12b`)
